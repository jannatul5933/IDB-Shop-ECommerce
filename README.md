# IDB Shop (E-commerce)

A full-stack e-commerce web application built with Node.js, Express and MongoDB.

## Features
- User registration and login
- Admin login and product management (add, edit, delete, image upload)
- Product listing, shopping cart, buy now and checkout
- Real-time updates using Socket.IO

## Technologies
- Node.js, Express.js
- MongoDB with Mongoose
- jQuery, HTML, CSS
- Multer (image upload), Socket.IO, bcryptjs, express-session

## How to run
1. Install Node.js and MongoDB.
2. Open a terminal and go to the project folder: `cd E-commerec`
3. Run `npm install`.
4. Copy `.env.example` to `.env` and set your own values (admin password, session secret).
5. Run `npm start` and open http://localhost:3000
